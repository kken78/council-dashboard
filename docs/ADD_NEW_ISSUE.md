# 新しい号を追加する手順

1. `data/_template.json` を `data/issue-NN.json` にコピー（NNは号数）。
   会議録がすでに公開されていれば、`python scripts/draft_issue.py NN "令和◯年◯月定例会議"` で
   会議録から質問者・発言順・よみ・会議録リンクを埋めた下書き（`data/drafts/issue-NN.draft.json`）を作れる。
   質問の題名は「（仮：会議録から推定）」付きの仮の値なので、議会だよりの一覧表の題名に置き換える。
2. 議会だより・会議録から、各議員の問・答を流し込む。
   - 3問以上の議員は、目次（P.8 一覧表）で**〇の付いた番号だけ** published:true。
   - 未掲載は title だけ書き、published:false（q/a/o は不要）。
   - テーマは config.json の themes の id から選ぶ。主テーマは必ず1つ。
   - 分野をまたぐ質問（例：物価高騰の商工業者支援と福祉施設への影響）は、主たる分野を `theme`
     に、もう一方を `sub_themes`（配列・省略可）に書く。副テーマは絞り込みと検索に効くだけで、
     件数集計・グラフには入らない。迷ったら主テーマだけにしておく。
   - `links.minutes` は**会議録のページ**（ページタイトルが「令和◯年◯月定例会議・会議録」のもの）を入れる。
     「本会議のご案内」ページ（タイトルに「会議録」が付かない）を入れると、会議録検索・統合MCPとの照合が失敗する。
     会議録がまだ公開されていない号は案内ページを仮に入れてよいが、公開後に会議録ページへ差し替える。
3. `python scripts/validate.py` で検査（キー重複・テーマ名・掲載なのに本文空・一覧表との件数照合・会議録リンク）。
   `--online` を付けると、会議録リンク先のページタイトルも確認する（要ネット）。
4. `python scripts/build_minutes_map.py` で会議録のやりとりへのリンク表を更新（会議録が未公開なら後で `watch` ワークフローが自動で行う）。
5. `python build.py` で docs/ を再生成（または GitHub Actions が自動実行）。
6. 既存の号ファイルには触らない。差分は新ファイルだけ（会議録リンクの差し替えは `watch` ワークフローの PR で行う）。

> 元データは PDF より会議録・確定テキストの方が正確。可能なら事務局に確定テキスト（または会議録）の提供を依頼する。
